# Tabcord

Show which browser you're using, and the page or video you're on, on your Discord profile.

```
Browsing: Lofi Beats
in Opera GX · YouTube
```

Everything is one Python file, [`tabcord.py`](https://github.com/iraqerrorr/Tabcord/blob/main/tabcord.py), with **no external dependencies** and nothing else to install.

## Features

- Detects your browser: Opera GX, Opera, Chrome, Edge, Firefox, Brave, Vivaldi
- Shows the title of the tab you're on, and recognizes sites like YouTube, Twitch, Netflix, Disney+, Prime Video, Hulu, Crunchyroll, Max, Kick, Spotify, SoundCloud, Apple Music and Deezer
- Picks the browser you're focused on if several are open
- Hides titles in Incognito / InPrivate / Private windows
- Turns off automatically when you close the browser, and clears your status on exit

## How it works

The script reads the title of your browser window, builds a status, and sends it to the Discord desktop app over Discord's local IPC pipe. Nothing is sent to any server.

## Requirements

- Python 3.8 or newer
- **Discord desktop app** running (the web version can't receive presence)
- **Windows** to read page titles. On macOS/Linux it can only show the browser name.

## Setup

### 1. Create a Discord application

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications) and click **New Application**.
2. The **application name** is what appears after "Playing" on your profile (for example, `Tabcord`).
3. Copy the **Application ID**.
4. *(Optional)* Under **Rich Presence > Art Assets**, upload images named: `operagx`, `opera`, `chrome`, `edge`, `firefox`, `brave`, `vivaldi`. Without them the status still works, just without a logo.

### 2. Configure the script

Open `tabcord.py` and paste your Application ID:

```python
CLIENT_ID = "PASTE_YOUR_APPLICATION_ID_HERE"
```

### 3. Turn on activity sharing in Discord

**User Settings > Activity Privacy > Share your detected activities with others**

### 4. Run it

```bash
python tabcord.py
```

Open your browser and check your Discord profile. Press `Ctrl+C` to stop; it clears your status on exit.

## Configuration

Options are at the top of `tabcord.py`:

| Option | Default | What it does |
|---|---|---|
| `CLIENT_ID` | *(required)* | Your Discord Application ID |
| `SHOW_TITLE` | `True` | `False` = only show the browser name, never page titles |
| `HIDE_PRIVATE` | `True` | Hide titles in Incognito / InPrivate / Private windows |
| `CHECK_EVERY` | `15` | Seconds between checks (Discord rate-limits faster updates) |

## Privacy

- Page titles are visible to anyone who can see your Discord profile. Set `SHOW_TITLE = False` if you only want the browser name shown.
- Private / incognito window titles are hidden by default.

## Troubleshooting

| Problem | Fix |
|---|---|
| Nothing shows on Discord | Use the **desktop** app, enable *Share your detected activities*, and make sure your status isn't Invisible |
| "Can't reach Discord" in the output | Start Discord first, then the script |
| Still not connecting | Run Discord and the script at the **same admin level** (normally both non-admin). Reinstall Discord if it asks for admin every launch |
| Two Discord clients open | Close extras (Canary/PTB); Rich Presence works with one client |
| No logo on the profile | Upload art assets with the exact names listed above |
| No page titles | Page titles only work on Windows |

## Limitations

- It only sees the **active tab** of the focused browser window, not background tabs, and it can't tell whether a tab is actually playing audio.
- Page titles are read on Windows only.
- Discord limits how often presence can update, so changes can take up to `CHECK_EVERY` seconds to appear.
